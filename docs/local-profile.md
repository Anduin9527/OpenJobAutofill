# 本机资料维护

固定资料文件为仓库目录下的 `local-profile/profile.json`。整个 `local-profile/` 目录已被 Git 忽略，不能强制添加到 Git，也不要把实际个人信息复制进测试、日志或示例资料。

后续补充资料时，以该文件为基准原位更新，不再生成日期命名的平行版本。用户提供更新的插件导出时，以用户明确指定的导出为基准，完整保留 `values`、`custom`、`customSections` 及其他扩展字段，只改动本次要求的内容。

浏览器插件资料与此文件不是自动同步的：在设置页导入该文件后才生效。在插件中修改过资料后，先导出并用新导出更新此固定文件，再继续维护，避免旧文件覆盖新字段。

该文件不属于扩展发布内容。使用 Git 归档发布时不会包含它；手动压缩扩展目录时必须排除 `local-profile/`。原始下载文件保留作为来源，不作为日常维护入口。
