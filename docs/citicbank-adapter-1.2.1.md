# 中信银行招聘适配（1.2.1）

2026-09-29 在用户登录后的 [中信银行招聘页面](https://job.citicbank.com/#) 只读检查校园招聘简历编辑页。编辑页位于同源 `#myFram` 内，实际路径为 `/CustStyle/zpmhys/addSchoolResume4.html`。未填写、保存或提交在线简历，未将账号或简历值写入测试资料。

## 实现

- 弹窗每次操作重新发现唯一的简历框架，脚本注入和消息都指定同一个 `frameId`。首页、登录页或多个候选框架不执行填写。消息响应丢失后不自动重放填写。
- `src/citicbank.js` 独立实现站点与控件适配，由 `src/content.js` 接入，其他域名不启用。
- 表格单元格首个标题作为标签；依据 `way-data` 区分同一格内的证件类型/号码、电话类别/号码。隐藏存储输入框、下拉代理与搜索框不重复计数。
- Bootstrap Select 通过所属菜单的公开选项点击，等待 native select 选中状态与按钮显示同步；支持搜索、多选、异步出现的选项，拒绝歧义和禁用选项。
- `.dis-flex` 内省市区及二级选择合并为单个字段，按显式完整路径逐级选择并等待子选项。成功后检查全路径。
- 日期仅接受有效完整年月日，不从年月资料推测日期。期望薪酬仅在来源明确标注“税前年薪（万元）”时自动写入，不换算月薪。
- `way-repeat-wrapper` 下数字 `way-scope` 识别重复记录，结合表单 ID 判定栏目。学校/单位/项目/家庭姓名用于唯一身份绑定，空白记录只在有足够依据时匹配。教育记录还检查学历选项，避免高中限定行接收本科资料；同一资料条目不分配给两行。绑定约束同时用于本地和 AI 候选。
- 等待复用已有有界 runtime，结束后释放观察器；没有新增常驻轮询、依赖或浏览器权限。

## 验证与边界

14 个 Node smoke 测试文件通过；浏览器中信银行结构复刻 14 个用例、既有控件 25 个用例通过。包含框架路由、标签、下拉事件/显示同步、重复和禁用选项、多选集合、联动、日期、薪酬单位、隐藏字段、记录归属及高中/本科混排。浏览器用例检查等待器和观察器归零。

复现：执行 `node tests/citicbank-frame-smoke.mjs`；启动 `node tests/serve-browser-fixtures.mjs`，在浏览器打开 `http://127.0.0.1:4178/citicbank`（中信）和 `/`（既有控件）。测试页只使用虚构资料，并模拟观察到的 DOM 与事件响应。

这些测试不等同于真实站点填写/保存验证。社招简历页、后台联动数据以及所有学位/专业目录分支未实测。联动值当前要求 `省 / 市 / 区县` 等完整分级名称；无分隔的地址、缺失级别、未知选项留待手动处理。子级失败时可能已改变上级，结果会报未完成，需要核对。没有足够身份信息的语言、证书等重复记录不自动按序号套用，可使用定点填写。扩展不自动新增经历，不选择附件，也不点击本站保存或提交。

更新后在扩展管理页对原有 OpenJobAutofill 点击“重新加载”，打开简历编辑页后使用扩展。已有未保存内容先由用户处理，再决定是否刷新网页。
